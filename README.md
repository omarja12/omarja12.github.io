## ✏️ Update Projects

Edit `src/components/Portfolio.jsx` and modify the `projects` array:

```jsx
{
  id: 1,
  title: 'Your Project',
  category: 'quant',  // quant, ml, nlp, cv, optimization, blockchain
  description: 'What it does',
  highlights: [
    'Result 1',
    'Result 2',
    'Result 3'
  ],
  tech: ['Tech1', 'Tech2', 'Tech3'],
  link: 'https://github.com/omarja12/your-repo',
  image: '📊'  // emoji
}
```

Then deploy:
```bash
npm run deploy
```
